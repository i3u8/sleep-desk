# 睡眠声音事件与周期：麦克风方案简报（产品 / 研发）

> 面向 sleep-desk（健康 / 睡眠桌面）Android：仅麦克风夜间事件 + 可选手机辅助信号（亮屏 / 充电等），**不做 EEG、不做可穿戴心率**。  
> 目的：回答「声音何时出现」「能否估周期」「时间轴怎么画」「哪些话不能说」。  
> 偏好：同行评审 / 睡眠医学概念（AASM 分期思路）> SEO 博客。文末附链接与不确定性标注。  
> 撰写：2026-10-01（Asia/Shanghai）

## 0. 术语速览（AASM 思路，非完整评分手册）

成人多导睡眠（PSG）按 **30 秒 epoch** 标为：W（醒）、N1、N2、N3、R（REM）。日常科普常把 N1+N2 叫「浅睡」、N3 叫「深睡 / 慢波睡」。一夜约 **4–6 个 NREM↔REM 超日周期（ultradian）**，周期长度约 **~90 分钟**（个体与年龄差异大）；**前半夜 N3 更多，后半夜 REM 更长**。

权威入口（需机构订阅完整手册）：[AASM Scoring Manual](https://aasm.org/clinical-resources/scoring-manual/)

**重要边界**：麦克风听到的是**声学事件与粗行为代理**，不是脑电分期。下文「常见于某期」均指 PSG 文献中的**统计倾向**，不能反推「出现该声音 = 一定是该期」。

## 1) 常见夜间声音通常落在睡眠周期的哪一段？

下表按「临床 / PSG 文献倾向」整理，供事件标签与时间轴解释文案使用。

| 声音 / 事件 | 文献中更常见的阶段 / 时机 | 机制要点（简述） | 置信度 |
|-------------|---------------------------|------------------|--------|
| **打鼾（孤立 / 原发性）** | **N2、N3 占比较高；REM 相对较少** | 需一定咽壁张力才能振动发声；N3 塌陷不完全时更易「响而不停」 | 中高（PSG） |
| **呼吸暂停相关声**（窒息后喘息、断续鼾、喘鸣样喘醒） | 呼吸事件本身常在 **N2 与 REM 更突出**；**N3 中呼吸事件通常很少** | REM 上气道更易塌陷；事件后常接微觉醒 / 体动 | 高（OSA 分期依赖常见） |
| **咳嗽** | **以清醒段为主**；睡眠中 **N3 最少**；N1/N2/REM 高于 N3 | 睡眠对咳嗽反射有抑制；多数「夜咳」其实发生在醒着时 | 高（PSG+麦克风研究） |
| **梦呓 / 说梦话（somniloquy）** | **NREM 与 REM 均可**；孤立说梦话历史上更多记在 **NREM（尤其 N2）**；REM 片段可更情绪化 | 属正常变异型 parasomnia；可与其他 parasomnia / RBD 共病，分布会变 | 中（定义与样本异质） |
| **磨牙（bruxism / RMMA）** | 多数在 **浅 NREM（N1–N2，约 60–80%）**；**N3 与 REM 少（常 <10%）**；常在**周期上升支 / 进入 REM 前**成簇，并伴随 **微觉醒** | 中枢驱动 + 自主神经觉醒序列，非单纯「牙齿摩擦」 | 高（SB 文献一致） |
| **翻身 / 窸窣 / 大肌群体动** | **N3 最少**；N1、REM、N2 相对更多；体动常伴随 **阶段转换或觉醒** | 深睡运动抑制强；体动本身是「不安稳」代理，不是分期金标准 | 中高 |

### 1.1 打鼾 vs 呼吸事件（产品文案易混点）

- **孤立打鼾时间**：成人轻度 OSA / 打鼾队列中，鼾时长常集中在 **N2（可占鼾时长大半）与 N3**，**REM 占比较低**（PLOS One 2024，成人 n=93、儿童 n=47）。  
- **呼吸事件时间**：同一研究中，呼吸事件在成人更偏向 **N1/N2 + REM**，**N3 极少**。  
- 含义：时间轴上「持续鼾声」**不等于**「深睡不好」；有时恰恰是**气道振动但尚未塌成事件**。反过来，**安静段也不能标成「深睡」**——REM 也可因肌张力低而少鼾多事件。

来源：[Suzuki et al., PLOS One 2024](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0295232)

OSA 分期表型：约半数成人 REM-AHI ≥ 2× NREM-AHI（中位 REM/NREM≈2.2），但严重 OSA 也可呈 NREM 主导——**个体差异大**。[JCSM / Eiseman et al.](https://jcsm.aasm.org/doi/10.5664/jcsm.2258)

### 1.2 咳嗽

- 夜咳在 **醒期显著多于睡眠期**；睡眠内 **N3 咳嗽率最低**（Eni et al., PLOS One 2022，n=89 PSG+非接触麦）。  
- 经典 COPD 小样本：约 **85% 咳程在 EEG 确认的清醒**，真睡眠中极少，几乎无 3–4 期咳（Power et al., 1984）。  
- 产品含义：把「夜咳」当「睡眠质量差」可以；把夜咳峰直接标成「浅睡」要谨慎——很多其实是**夜间醒着咳**。

来源：[Eni et al., PLOS One 2022](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0262240)

### 1.3 说梦话

- ICSD / 综述立场：可发生在 **REM 与 NREM**（与多数「只在某期」的 parasomnia 不同）。  
- 实验室与综述常见叙述：孤立说梦话更多出现在 **NREM**；REM 话语可能更完整 / 情绪化（样本小、定义不一）。  
- 与 RBD、NREM 觉醒 parasomnia 共病时，阶段分布会被病理样本扭曲——**不要用说梦话单点推断 REM**。

来源概述：[Sleep Foundation — Sleep Talking](https://www.sleepfoundation.org/parasomnias/sleep-talking)；综述 Alfonsi et al. 2019（Sleep Medicine Reviews 方向）

### 1.4 磨牙（睡眠磨牙症）

- 健康 / 典型 SB：**RMMA 主要在 N1–N2**；**N3 <~5%，REM <~10%**（多篇一致）。  
- 常在 **NREM→REM 过渡前、周期上升段**成簇，并与 **微觉醒 + 交感激活** 相连。  
- 声学上：短促、节律性咬合声 / 摩擦声；易与鼾尾、吞咽混淆——检测需谨慎，诊断仍属牙科 / 睡眠医学范围。

来源：[Kato et al. 叙事综述 / Europe PMC 37114936](https://europepmc.org/article/MED/37114936)；经典比例见 Journal of Orofacial Pain 等 SB 综述

### 1.5 窸窣 / 翻身相关声

- 视频-PSG：健康人夜间大肌群运动 **N3 最少**，N1 / REM 相对多。  
- 体动常是 **觉醒、阶段切换、呼吸事件后** 的伴发表现。  
- 麦拾取的「床单窸窣」= **运动代理**，分辨率低于视频 / 加速度计；双人床 / 宠物会污染。

不确定性：**高**——「安静 = 深睡」在营销里常见，但科学上只是弱代理（REM 也可安静）。

## 2) 仅靠麦克风（+ 手机辅助）能估睡眠周期吗？诚实边界

### 2.1 科学上「可以做到什么」

| 目标 | 仅麦 / 麦+手机辅助 | 诚实表述 |
|------|-------------------|----------|
| 睡眠/清醒粗分（整夜时长、入睡/起床） | 可行；亮屏、解锁、充电、静止时长可补 | 「估计睡眠时段」，误差常十几到几十分钟，取决于放手机习惯 |
| 三分类：Wake / NREM / REM | 研究级 DL 在家庭麦上约 **~75% epoch 准确率**（κ 中等） | 「研究模型代理分期」，非临床 hypnogram |
| 四分类：Wake / Light / Deep / REM | 手机麦芯片研究约 **~68–70%** 一致率；共享卧室更差 | 不适合向用户展示为「医学分期」 |
| 真正 AASM hypnogram | **做不到**（缺 EEG/EOG/EMG） | 禁止宣称 |

代表性研究（研究场景，非消费 App 已获监管认证）：

- **HomeSleepNet（家庭智能手机音频，三分类 W/REM/NREM）**：准确率 **76.2%**，macro-F1 **0.714**，κ **0.557**；对 wake/REM 仍较弱（~63–65%）。[JMIR 2023](https://www.jmir.org/2023/1/e46216)  
- **麦克风芯片端到端四分类**：约 **70%**；外推智能手机集约 **68%**。[Nat Sci Sleep 2022 / PubMed 35783665](https://pubmed.ncbi.nlm.nih.gov/35783665/)  
- 手机**屏幕事件 / 充电**等：主要用于 **睡眠时长与作息**（如 SensibleSleep、iSenseSleep 一类工作），**不能可靠分期**。

### 2.2 可选手机辅助信号的诚实用法

| 信号 | 建议用途 | 勿过度解读 |
|------|----------|------------|
| 亮屏 / 解锁 / 互动 | 标记「可能醒着」、修正入睡/起床 | 睡前刷手机、夜醒不看手机都会偏 |
| 充电状态 | 粗锚定「在床边 / 静止场景」 | 充电 ≠ 睡着 |
| （若有）加速度静止 | 体动代理，辅助「不安稳」层 | 手机不在床上则失效 |
| 麦克风事件密度 | 呼吸声规律性、鼾、咳、体动簇 | 噪声、伴侣、空调严重干扰 |

**无 EEG / 无 HRV 时的合理产品叙事**：

1. **事件时间轴（主产品）**：检测到什么、何时、多密——这是麦克风的强项。  
2. **不安稳 / 相对安静 的启发式色带（次产品）**：用事件率、体动代理、可选屏幕打断做 **低置信「活动带」**，明确写「非脑电分期」。  
3. **周期「示意」**：若要画 ~90 min 波浪，应标为 **「示意超日节律 / 基于声音活动的粗估计」**，或仅在研究模型达标且 disclaimer 齐全时提供「代理 REM/NREM 带」——**默认不建议对消费者宣称已识别 REM**。

### 2.3 营销夸大 vs 诚实表述（对照）

| 营销易说 | 更诚实 |
|----------|--------|
| 「麦克风睡分仪 / 医学级 hypnogram」 | 「基于夜间声音与手机状态的**睡眠活动估计**」 |
| 「精确深睡 / REM 分钟数」 | 「相对安静段 / 声音活跃段」或「研究级代理分期（有误差）」 |
| 「检测到呼吸暂停确诊 OSA」 | 「可疑呼吸相关声音模式；需 PSG/HSAT 医疗评估」 |
| 「磨牙已确诊」 | 「疑似节律性咬合相关声音；请口腔/睡眠专科」 |

## 3) Android 时间轴：建议图层与禁止声明

### 3.1 建议绘制的层（自下而上）

1. **时间轴底（时钟）**  
   - 入睡估计 → 起床估计（可用麦安静开始 + 屏幕/充电辅助）。  
   - 标注「估计」，允许用户微调。

2. **声音事件层（核心，高可信展示）**  
   - 类别：鼾声、疑似呼吸中断后喘息、咳嗽、语音/梦呓、疑似磨牙、体动窸窣、其他突发声。  
   - 用**图标/短竖线/热力密度**，不要用脑电色标冒充分期。  
   - 点击：时长、响度代理、置信度、「可能误检」提示（双人床）。

3. **声音活动 / 不安稳带（可选，中低可信）**  
   - 例如：低 / 中 / 高「声学活动」三档，或连续透明度。  
   - 文案：**「夜间声音与体动活跃度（非睡眠分期）」**。

4. **打断层（手机辅助）**  
   - 亮屏、解锁、来电、充电拔插等竖线。  
   - 解释为「可能清醒或干扰」，不自动等于觉醒 epoch。

5. **（可选）研究级代理分期带**  
   - 仅当内部模型有验证指标、且 UI 明确「实验性 / 非医疗」时开启。  
   - 最多展示 **清醒 / 睡眠** 或 **清醒 / 相对 NREM 样 / 相对 REM 样** 三色，**禁止**画成标准五期 hypnogram 并给出医疗结论。

6. **汇总卡（诚实数字）**  
   - 总卧床、估计睡眠、鼾时长或指数、咳次数、体动簇次数、最长安静段。  
   - **不要**默认输出「深睡 XX 分钟、REM XX 分钟」除非代理模型 + 强 disclaimer。

### 3.2 视觉与文案：不要声称的内容

- ❌ 「本图为标准睡眠分期图 / hypnogram」  
- ❌ 「已精确识别 N1/N2/N3/REM」  
- ❌ 「根据鼾声证明您进入深睡」  
- ❌ 「麦克风可替代多导睡眠监测」  
- ❌ 把单次咳、说梦话标成疾病诊断  

- ✅ 「夜间声音事件时间线」  
- ✅ 「声学活跃度（估计）」  
- ✅ 「可疑呼吸相关声音——建议咨询医生」  
- ✅ 「双人同床时事件可能来自同伴」

### 3.3 与事件类型挂钩的「弱提示」（非诊断）

可在详情页用**软性、可折叠的科普**，不要写进主标题：

- 成簇磨牙样声 →「文献中多见浅 NREM / 觉醒相关」  
- 持续平稳鼾 →「可见于 N2/N3；不等于无呼吸暂停」  
- 断续鼾 + 喘息/安静后突然响 →「更像呼吸事件相关模式」  
- 咳高峰在夜醒/早晨 →「常与清醒相关」  
- 大段安静 →「可能是深睡、REM 或只是您睡得很静——无法单靠麦区分」

## 5) 不确定性与产品风险清单

1. **个体与表型差异大**（REM 主导 vs NREM 主导 OSA；共病改变磨牙/说梦话分布）。  
2. **家庭噪声**：伴侣、宠物、空调、电视 → 假阳性事件与假「不安稳」。  
3. **麦克风分期 κ 中等**：即便 SOTA 研究，wake/REM 混淆仍常见；消费场景通常更差。  
4. **监管与话术**：避免医疗器械式宣称；呼吸暂停、磨牙症需导向专业评估。  
5. **「安静 = 深睡」是常见谬误**：REM 也可安静；N3 反而可有持续孤立鼾。  
6. **文献年代与样本**：部分咳嗽/说梦话经典研究样本小；优先用带 PSG 金标准的近期工作校准产品假设。

## 6) 给研发的一页结论

- **麦克风的主价值 = 事件检测与时间线**，不是替代 PSG。  
- 声音与分期的关系是**概率先验**，可做科普与弱提示，不可做硬标签反推。  
- 可视化默认：**事件层 + 声学活跃度 + 手机打断**；代理周期带仅实验开关。  
- 对用户一句话：**我们记录夜间声音与活动，帮助你看清干扰与模式；真正的睡眠分期仍需要脑电等医学检查。**
